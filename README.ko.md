# clipring

Claude Code 프롬프트 입력창을 위한 킬 링(kill ring)입니다.

[English](README.md)

## 왜 필요한가요

프롬프트를 쓰다가 갑자기 다른 일이 생기거나 마음이 바뀔 때가 있어요. 쓰던 내용을 잠깐 치워 두고 다른 말을 먼저 입력해야 하는데, 쓰던 걸 잃고 싶지는 않죠.

긴 프롬프트를 보냈는데 Claude의 답이 기대와 다르게 나오기도 해요. 그럴 땐 쓰던 글을 잠시 접어 두고 다른 메시지를 먼저 보낸 다음, 나중에 돌아와 이어 쓰고 싶어져요.

뭔가를 복사해 뒀다가, 프롬프트를 몇 번 보낸 뒤에 붙여넣고 싶을 때도 있고요.

clipring은 이 세 가지를 해결해요. 키 하나로 한 줄(또는 입력 중인 전체 내용)을 잘라내면, 재시작해도 남는 기록에 쌓입니다. 프롬프트 위의 띠에는 치워 둔 내용이 보이고, 다른 키를 누르면 커서 위치에 다시 붙여넣어요. Emacs를 써 보셨다면 킬 링과 같은 방식이라고 보시면 됩니다.

## Install

터미널 세션의 프롬프트에서 다음을 입력하세요.

```
/plugin install clipring --marketplace summerz/clipring
```

마켓플레이스를 추가할지 물으면 `y`로 답하고 범위(scope)를 고르세요. 셸에서는 `claude plugin install clipring --marketplace summerz/clipring`으로 설치할 수 있어요. 데스크톱 앱에서는 `/plugin`이 동작하지 않아요. 이때는 프롬프트 입력창 옆의 +를 누르고 Plugins, Add marketplace에 `summerz/clipring`을 입력한 뒤 Add plugin을 누르세요.

## 기능

프롬프트 입력창에서 잘라낸 텍스트는 최대 50개까지 기록에 쌓여요. 기록은 세션이 바뀌어도 유지되고, 잘라낸 텍스트는 시스템 클립보드에도 복사됩니다. 프롬프트 위의 띠에는 선택된 클립과 전체 개수가 표시돼요. 띠와 도움말에서는 단축키가 ⌥⌫ 같은 기호로 보입니다.

`/clips`를 입력하면 전체 목록 창이 열려요. Enter로 붙여넣고 Esc로 닫으면 됩니다.

연속해서 잘라내면 Emacs의 kill처럼 하나의 클립으로 합쳐져요. 커서는 윗줄 끝에 놓이니까, 같은 키를 다시 누르면 위쪽으로 계속 잘라냅니다.

Shift+왼쪽/오른쪽으로 텍스트를 선택할 수 있어요. 다음에 잘라내면 선택한 영역을 가져갑니다.

ctrl+u, ctrl+k로 지운 내용도 링에 들어가요. 줄 전체를 지우면 줄 잘라내기로 취급해요. 그래서 cmd+backspace를 ctrl+u로 보내는 터미널에서도 cmd+backspace가 잘 동작합니다.

한국어(2벌식) 입력 상태에서도 단축키는 그대로 동작해요.

## 키

표에는 `option+backspace` 식으로 적었어요.

| 키 (기본값) | 동작 |
| --- | --- |
| `option+backspace` | 선택 영역을 잘라내요. 선택한 게 없으면 커서가 있는 줄을 잘라내요 |
| `ctrl+option+backspace` | 입력 중인 전체 내용을 잘라내요 |
| `option+up` | 더 오래된 클립을 선택해요 |
| `option+down` | 더 최근 클립을 선택해요 |
| `option+v` | 선택한 클립을 커서 위치에 붙여넣어요 |
| `option+d` | 선택한 클립을 삭제해요 |
| `option+c` | 전체 목록을 열거나 닫아요 (`/clips`도 가능해요) |
| `option+h` | 도움말 창을 열거나 닫아요 |
| `shift+left` / `shift+right` | 텍스트를 선택해요 |
| `cmd+v` | 시스템 클립보드의 마지막 잘라낸 내용을 붙여넣어요 |
| 창 안에서: `enter` | 붙여넣어요 |
| 창 안에서: `d` | 삭제해요 |
| 창 안에서: `esc` | 창을 닫아요 |

## 키 바꾸기

모든 단축키는 설정값이라 바꿀 수 있어요. 설정 메뉴의 플러그인 항목에서 바꾸거나 `~/.claude/settings.json`을 고치세요.

```json
{ "pluginConfigs": { "clipring": { "paste": "alt+p", "cut": "ctrl+x" } } }
```

표기법은 이래요. `ctrl`, `alt`(또는 `option`), `shift`를 `+`로 이어 붙이고, 마지막에 키(`backspace`, `up`, `down`, `left`, `right` 또는 영문자)를 쓰세요. 바꾸면 모드가 바로 다시 로드됩니다. Shift+왼쪽/오른쪽 선택과 창 안의 `d`는 바꿀 수 없어요.

## 참고

1. 대부분의 터미널에서는 shift+up/down이 프롬프트 입력창에 전달되지 않아요. 그래서 세로 선택은 없습니다. 대신 잘라내기를 반복하세요.
2. 띠의 버튼은 프롬프트 입력창이 키를 먼저 받지 않을 때, Claude Code 키바인딩을 통해 기본 단축키에도 반응해요. 바꾼 단축키는 프롬프트 입력창에서만 동작합니다.

필요하다면 쓸 수 있는 팁이에요. `~/.claude/keybindings.json`에 option 키 조합을 넣을 수 있어요. 모드의 버튼은 엔진이 동작에 연결해 둔 키만 받을 수 있기 때문에, 띠의 버튼이 입력창 밖에서도 기본 단축키에 반응하길 원할 때 이 파일을 쓰시면 됩니다. 그럴 일이 없다면 건너뛰어도 괜찮아요. 다만 Global의 `meta+up` / `meta+down` 항목은 해당 키의 Claude Code 기본값(`app:diffFileListUp` / `app:diffFileListDown`, ctrl+up / ctrl+down에는 그대로 남아요)을 덮어써요. 되돌리려면 그 파일에서 `clipring`이라고 표시된 블록을 지우세요. 기본값이 다시 살아납니다.
